# magimira-procon2025
『初音ミク「マジカルミライ 2025」』プログラミング・コンテスト応募作品

## ビルド方法
1. Unityディレクトリでプロジェクトをビルドし、Unity/Buildsとして保存。
2. Buildsディレクトリ内のindex.htmlをJS/index.htmlの内容に置き換え、JS/text-alive.jsをUnity/Buildsディレクトリ直下へコピー。
3. サーバーを起動し、Unity/Builds/index.htmlを開くと確認ができます。
